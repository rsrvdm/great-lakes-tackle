# Great Lakes Tackle: website and online store (design preview)

Design mockup for Great Lakes Tackle, Tuncurry NSW, prepared by MidCoast Web Co. Not a live store.

- `index.html` is the built single-file homepage preview (open it in a browser).
- `src/src.html` is the editable source with image placeholders. `python3 src/build.py` inlines `assets/` and rebuilds `index.html` (run from the repo root).
- `assets/glt-logo-original.jpg` is the client's logo, used unchanged.

## Placeholders to replace before launch
- Hero, category, product and coastline photos are cropped from a design reference. Replace with licensed or shop-owned photography.
- Products, prices and the giveaway entry box are samples. Giveaway terms need the owner's approval.
- Click and collect process, hours and copy are drafts.
